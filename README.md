# TaskFlow ⚡ - Modern Landing Page

TaskFlow is a modern, high-performance, and visually stunning landing page for a next-generation project management platform. Designed for agile teams, it showcases a seamless user experience for managing tasks, tracking team velocity, and streamlining workflows with AI-powered suggestions.

Built with **React**, **JSX**, and **Tailwind CSS**, the project features custom inline styles for precision design, full responsiveness, smooth marquee animations, and highly interactive interactive UI elements.

## ✨ Features

- **Modern & Sleek UI/UX:** Built with a clean interface utilizing the *Plus Jakarta Sans* font and vibrant modern color gradients.
- **Interactive Mini Kanban Board:** A live-updating-style visual preview of tasks categorized by *To Do*, *In Progress*, and *Done* with tags and progress indicators.
- **Dynamic Logos Marquee:** A smooth, infinite horizontal scrolling marquee highlighting integrations like Slack, GitHub, Figma, Notion, and Stripe.
- **Feature Showcase:** Grid layout explaining key selling points like lightning-fast boards, AI task suggestions, and real-time reporting.
- **Tiered Pricing Component:** Beautifully structured billing toggle layout (*Free*, *Pro*, *Enterprise*) with highlight badges for the most popular plan.
- **Customer Testimonials:** High-fidelity social proof cards featuring reviews from industry leaders (Notion, Stripe, Figma, Vercel).
- **Fully Responsive Design:** Optimized with tailored CSS media queries to ensure an immaculate experience across mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack & Architecture

- **Frontend Library:** React (Functional Components & Hooks like `useState`, `useEffect`)
- **Styling:** Custom JS-in-HTML inline styling for scoped components alongside global utility treatments via `index.css`.
- **Typography:** *Plus Jakarta Sans* for clean, tech-focused readability and *Instrument Serif* for stylized branding elements.
- **Icons & Avatars:** Native rich Emojis integrated seamlessly for lightweight and universally supported visuals.

### Component Breakdown:
- `Navbar.jsx`: Smart navigation bar that dynamically triggers backdrop blurs and borders upon scrolling.
- `Hero.jsx`: Main introduction section containing the eye-catching interactive mini Kanban board.
- `LogoBar.jsx`: Infinite scrolling loop showcasing enterprise integrations.
- `Features.jsx`: Grid-based presentation of platform capabilities with hover animation effects.
- `Pricing.jsx`: Interactive tier-based pricing structure.
- `Testimonials.jsx`: Grid layout displaying user reviews and star ratings.
- `Cta.jsx`: High-conversion Call-to-Action section directing users to start free or contact sales.
- `Footer.jsx`: Comprehensive clean multi-column footer containing links, copyright data, and credits.
